Recordings are NOT stored in git — only metadata files are.

Raw sessions live in the shared Drive folder [https://drive.google.com/drive/folders/1ECN5H2yQYmT6C6N3y5NRC3LNGPhXoYr7], organised as
`<room>/<date>/<label>_<session>.csv` with a matching `_meta.json`.

Each `_meta.json` records: label, room, date, subject, board positions,
distance, obstruction material, sampling rate, firmware commit hash.
